# Build report - German A1-B1 pack (corpus-tagged)

Generated by `tools/build_pack.py` on every full run. Everything outside the `manual` markers is regenerated; the manual section (QA verdicts, check output) is preserved.

## Tagging

- Tagger: spaCy 3.8.16, de_core_news_sm 3.8.0 (parser and NER disabled).
- Corpus: 781,130 Tatoeba German sentences; 496,173 have an English translation and were tagged (4,206,726 tokens).
- Tagging wall time: **953.6s** (6 processes; cached in `.cache/derived/tagged_*.jsonl.gz`, keyed by tag version + spaCy/model version + corpus signature).
- Sentence-initial capitals lowercased before tagging (truecasing, proper nouns kept): 383,520 sentences.
- Sentences with a permissively licensed recording: 4,928.

participles shared by two verbs (gehört: hören), the demonstrative das before
